## Fixes

- **New game world map intro:** the text no longer stops advancing after the first lines, and skipping the intro with Start now continues into the prologue instead of leaving the game stuck.
- **Optimized-build hangs:** about 90 game functions from the original code end without returning a value. On the GBA that is harmless, but the optimized PC/Android build turned it into wrong results. Every one of them now returns a proper value, which also removes possible hangs or glitches in the trade menu, class promotion, villages, traps, the arena and the world map.

The Android version code is now 2, so this APK installs over 0.1.0.
